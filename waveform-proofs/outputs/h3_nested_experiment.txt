On the class-2 null D8 the assembled bracket is far from I (noise propagated through a
large [A,B] = -I), while on Z it is ~0: its null law depends on the unknown lower-depth
structure, so there is no world-free matched null for it. The direct readout's null law is
the same for every class <= 2 world.
Near the identity the opposite holds: the assembled bracket's error is suppressed by the
square of the single-loop holonomy size (plus a noise^3 floor, cf. Z), not ~ sigma_eff, so
assembling from single-loop estimates is far MORE efficient there (NN rows) -- the eps^-6
cost in section 3 belongs to the direct nested-loop readout, not to depth 3 as such. But it
is biased upward by noise-generated brackets and needs a model-based (fitted class-2) null;
not built here.

7. UNITARY SHORTCUT: depth 2 + unitarity + fiber dimension already exclude class 2
----------------------------------------------------------------------------------
If (A,B) in U(n) generate a class-2 non-abelian group, C=[A,B] is central, so on each
irreducible joint block of dim d it is a scalar c with c^d = 1 (det C = 1 on the block), and
c != 1 on at least one block. Hence ||C - I||_F >= g(n) = min_{2<=d<=n} 2 sqrt(d) sin(pi/d).
So 0 < ||[A,B] - I||_F < g(n) certifies class >= 3 from the depth-2 loop alone.

must not lean on the representation theory of U(n).
