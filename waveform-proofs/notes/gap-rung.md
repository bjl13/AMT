# The gap rung: class ≥ 3 from the depth-2 loop
## Using the U(n) spectral gap on H₂'s own commutator readout

**What it is.** H₃ §3 (`notes/h3-nested-rung.md`) observed that, for unitary holonomy in a fiber of known dimension n, a class-2 commutator cannot sit close to I: ‖[A,B] − I‖_F is either 0 or at least g(n). So a commutator loop that reads *confidently nonzero and confidently below the gap* already rules out class ≤ 2, without the nested loops. This note turns that observation into a calibrated test on H₂'s readout, measures what it costs, and states where it is valid.

**Claim language.** A positive result certifies **class ≥ 3**, a lower bound, exactly as H₃ does. It leans on unitarity and on n; H₃ does not.

Rigor flags: **[THM]** proved here; **[NUM]** numerical (`src/gap_rung_experiment.py`, output in `outputs/gap_rung_experiment.txt`); **[OPEN]** open.

## 1. Where class-2 commutators can sit [THM]

**Proposition 1.** Let A, B ∈ U(n) generate a group of class ≤ 2, and C = [A,B]. Then C is unitarily conjugate to

  I_{n₀} ⊕ c₁ I_{m₁} ⊕ … ⊕ c_r I_{m_r},  n₀ + Σ m_j = n,

with each c_j a **primitive m_j-th root of unity** (m_j ≥ 2). Every such spectrum occurs (direct sums of clock-shift pairs). Hence

  ‖C − I‖_F ∈ {0} ∪ [g(n), ∞),  g(n) = min_{2 ≤ m ≤ n} 2√m sin(π/m),

and g(n) is attained by the clock-shift pair CS_m ⊕ I for the minimizing m.

*Proof.* Unitarity makes ⟨A,B⟩ completely reducible. Class 2 makes C central, so on each irreducible block of dimension d it is a scalar c (Schur), and AB = c BA there. Let m be the order of c. Then A^m B = c^m B A^m = B A^m, so A^m commutes with A and B and is a scalar on the block; likewise B^m. The algebra generated by A and B on the block is therefore spanned by A^i B^j with 0 ≤ i, j < m, so its dimension is at most m². Irreducibility makes it the full matrix algebra (Burnside), of dimension d², so d ≤ m. A commutator has determinant 1, so c^d = 1 and m | d. Hence d = m: every block where C ≠ 1 has dimension equal to the order of its scalar, and the order is exactly the block dimension. Grouping blocks with the same scalar gives the stated form. Clock and shift matrices of size m satisfy XZ = ω ZX with ω = e^{2πi/m}, so any listed spectrum is realized by a direct sum. A block with scalar c of order m contributes √m |1 − c| ≥ 2√m sin(π/m) to ‖C − I‖_F, and further blocks only add. ∎

This sharpens H₃ §3's proposition (which used only c^d = 1): it gives the *complete list* of class-2 commutator spectra, which is what an exact null needs. Counts for n = 2…8: 1, 2, 4, 7, 12, 20, 33. g(2) = g(3) = g(4) = 2.828, g(5) = 2.629, g(6) = 2.449, g(7) = 2.296, g(8) = 2.165. The output's §0 checks tightness on random-basis CS₃, CS₄, CS₅, CS₈, D8 and CS₂ ⊕ CS₃ (class-2 residuals ≤ 1.5 × 10⁻¹⁵; each CS_m hits 2√m sin(π/m) to four digits).

## 2. The test

Readout as in H₂: R shots Y = W + E, Ŵ = Procrustes(mean Y), d̂ = ‖Ŵ − I‖_F, noise scale from the tangent σ̂ with n²(R − 1) degrees of freedom (`notes/h2-tangent-backport.md`). At R = 1 there is no σ̂, and those rows use the true σ (an oracle row, for reference only).

The null "class ≤ 2" is a union: C = I, or C has one of the class-2 spectra of Proposition 1. The rung is an **intersection-union test** (Berger 1982): reject the union only if every piece is rejected at level α.

- **p_b**: H₂'s studentized tangent test of C = I (upper tail of d̂). This is H₂ unchanged.
- **p_a**: for each class-2 spectrum S with d(S) ≤ g(n) + 0.6, a lower-tail bootstrap-t p-value for d̂ against the exact law of d̂ when C ~ S. By unitary invariance of the readout noise, that law depends only on the spectrum, so S = diag of its eigenvalues is a valid representative. p_a is the maximum over these S.
- **Certify class ≥ 3** iff p_a < α and p_b < α. An IUT has size ≤ α with no multiplicity correction.

**The window.** Spectra with d(S) > g(n) + 0.6 are dropped from the max. This is a truncation, not a theorem: it is safe when the spread of d̂ is small against 0.6. The "binding spectrum" counts in §1 of the output show that only the spectra at or within 0.2 of g(n) ever give the max (e.g. CS₅ at R = 1: the 2.629 spectrum 1871 times, the 2.828 one 127 times, none farther out), and the calibration rows below are the check.

**The pivot order [THM, elementary; found NUM].** The bootstrap-t pivot is (d̂ − d(S)) / se^k. Generically k = 1: d̂ − d(S) is first order in the noise. When every eigenvalue of S is ±1 (D8, C = −I, the farthest point of U(2) from I), the linear term Re tr(W†X) vanishes and d̂ − d(S) is O(se²): noise can only pull d̂ *down*. A k = 1 pivot is then not pivotal, and the first run false-alarmed on D8 at 0.130 (R = 2) and 0.077 (R = 5). With k = 2 for those spectra, D8 reads 0.049–0.054 at every R. The bias itself is real (§1 of the output: P(d̂ < g(2)) = 1.000 on D8 at every R, mean shortfall 0.033 at R = 1), which is why a naive "d̂ < g" rule cannot be used.

## 4. Scope: where the rung is and is not valid [NUM]

**(a) n understated.** CS₅ (class 2, ‖C − I‖ = 2.629, in U(5)) tested against the spectra of a smaller assumed fiber: false certification 0.99–1.000 for assumed n = 2, 3; 0.855 (R = 5) and 1.000 (R ≥ 20) for n = 4. With the correct n = 5: 0.047 / 0.056 / 0.038. Using an n smaller than the true fiber is fatal.

**(b) Projected readout.** A class-2 pair in U(4) read through a 2-frame (top-left 2 × 2 of the loop action), tested as n = 2: the compressed block is not unitary, Procrustes forces it into U(2), and for CS₄ and D8 ⊕ I₂ it lands at ‖· − I‖ = 2.000, inside the gap. False certification 1.000 at R = 5, 20, 100. **The gap rung is invalid under projected readout.** H₂ is not affected in the same way for abelian worlds, whose compressed commutator block is exactly I.

**(c) n overstated.** The same U(2) worlds embedded as W ⊕ I₆ and read in full as U(8) (g(8) = 2.165): D8, WZ and Dgen certify at 0.000 (WZ and Dgen were 1.000 in U(2)); D16 (2.000 < 2.165) still at 1.000. Overstating n keeps size ≤ α and loses power for g(n_true) > ‖C − I‖ ≥ g(n_assumed). Conservative.

**(d) Non-unitary transport.** The GL(4) class-2 Heisenberg pair Heis(ε) has ‖C − I‖ = 0.354 at ε = 0.5 and 0.127 at ε = 0.3, well inside the gap. Read through the unitary pipeline it is falsely certified class ≥ 3 at 0.92 → 1.000 (ε = 0.5, R = 20 → 200) and 0.17 → 0.985 → 1.000 (ε = 0.3, R = 20 → 200 → 2000). Class-2 commutators are not quantized off U(n). **Unitary only.**

**What n means in practice.** Under full-frame unitary readout, n is the dimension of the readout matrix itself, so it cannot be misstated; (a) and (c) arise only when the frame is a projection of a larger fiber, which is case (b). The real conditions are therefore two: **full-frame readout** and **unitary (Kato) transport**. Under those, n is known for free.

## 5. Verdict

**GO, with scope.** For unitary holonomy read in full frame:

- The gap rung certifies class ≥ 3 from H₂'s depth-2 readout at size ≤ α (0.042–0.063 across every class ≤ 2 world tested, injected and transported).
- It costs what H₂ costs, R₈₀ ≈ 13 σ² ε⁻⁴, against H₃'s ≈ 7.5 σ² ε⁻⁶: 55× cheaper at ε = 0.1, ≈ 210× at ε = 0.05.
- Near the gap it needs only R ≈ 5 (R₈₀ = 4.6 at margin 0.028).

It does not replace H₃. H₃ remains the only class ≥ 3 certificate for non-unitary transport, projected readout, and any setting that must not lean on the representation theory of U(n).

**Changes to earlier claims.**

1. H₃ §3 states the gap with "c^d = 1 for a block of dimension d". The sharper statement (Proposition 1: block dimension *equals* the order of c) holds and gives the exact list of class-2 spectra. g(n) is unchanged.
2. H₃ §3's "any measured 0 < ‖[A,B] − I‖ < g(n) already certifies class ≥ 3" needs two qualifiers: *confidently* below g(n), with the second-order bias at C = −I handled (a raw d̂ < g rule false-alarms on D8 with probability 1), and full-frame readout. H₃ §3 lists "large or unknown fiber dimension" as the exception; under full-frame readout n is the readout dimension, so the operative exception is projected readout (§4b).
3. H₃ §3's list of worlds the shortcut covers is confirmed: D16, Q16, Dgen, WZ and NN(ε) are certified; D8 on the gap is correctly not.
